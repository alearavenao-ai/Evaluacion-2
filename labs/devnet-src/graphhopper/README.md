# Evaluacion2 - Software de Geolocalización y Rutas (GraphHopper)

## Descripción
Este proyecto consiste en una aplicación en Python que interactúa con las API REST de **GraphHopper** (Geocoding y Routing). La aplicación permite a los usuarios consultar coordenadas geográficas, calcular la distancia y duración del viaje entre dos puntos, y obtener instrucciones paso a paso para perfiles de transporte en vehículo (`car`), bicicleta (`bike`) o a pie (`foot`).

## Requisitos Previos
- Python 3.x instalado.
- Módulo `requests` de Python.
- Una clave de API válida de GraphHopper.
